# Fonts

- `NotoSansKR-Regular.otf`, `NotoSansKR-Bold.otf`: subsets of Noto Sans CJK KR (Regular, Bold) — Basic Latin, Latin-1, Hangul Jamo/Compatibility Jamo, all 11,172 Hangul syllables, general punctuation, arrows, CJK symbols, full-width forms and the 談 seal glyph. SIL Open Font License 1.1 (`OFL.txt`).
- Static cuts replace the former variable font, whose default instance is Thin (wght 100) and rendered too light in Unity's legacy Text; the Bold cut also avoids Unity's synthetic emboldening, which smears small Hangul.
